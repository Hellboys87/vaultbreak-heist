VAULTBREAK — The Meridian Job is a top-down 2D stealth heist game in plain Canvas JavaScript (no libraries, no network). Sneak a thief through the Meridian Museum at night, dodge patrolling guards and sweeping security cameras whose vision cones fill the ALARM meter, bag gems, gold bars and paintings by walking over them, steal the Meridian Diamond from the vault, and reach the exit pad before the alarm maxes out. Title, caught and clean-getaway screens, a heist timer, a loot HUD and restart are all included.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```
